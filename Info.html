1. Introduzione al linguaggio HTML

L'HyperText Markup Language, comunemente noto con l'acronimo HTML, è il linguaggio di marcatura più usato per i documenti web. Nato per la formattazione e impaginazione di documenti ipertestuali disponibili nel web 1.0, oggi è utilizzato principalmente per il disaccoppiamento della struttura logica di una pagina web e la sua rappresentazione, gestita tramite gli stili CSS per adattarsi alle nuove esigenze di comunicazione e pubblicazione all'interno di Internet.

2. HTML 5.0

HTML5 è la quinta versione principale dell'Hypertext Markup Language, il linguaggio di marcatura utilizzato per creare e strutturare contenuti sul web. HTML5 è stato introdotto per affrontare le nuove esigenze della navigazione moderna, rendendo il web più interattivo, semantico e compatibile con una vasta gamma di dispositivi. È stato progettato per migliorare l'integrazione di contenuti multimediali, la gestione delle applicazioni web e l'interazione utente senza dipendere da plugin esterni, come Adobe Flash, che sono stati frequentemente usati nelle versioni precedenti.

Le caratteristiche principali di HTML5

  • Multimedia integrato :
    Supporta nativamente video e audio con i tag video e audio, senza necessità di usare Flash o altri plugin.

  • Nuovi elementi semantici:
    Tag come article, section, header, e footer migliorano la leggibilità e struttura del codice.

  • Canvas :
    Il tag canvas permette di disegnare grafica dinamica e animazioni con JavaScript.

  • Storage locale :
    Web Storage LocalStorage e SessionStorage consente di memorizzare dati sul browser senza usare cookie.

  • Form migliorati :
    HTML5 introduce nuovi input per i form come date picker, email, URL, numero, range, ecc...

  • Responsive Design :
    Supporta un miglior adattamento per dispositivi mobili attraverso l’uso di CSS3 e media queries.

  • API avanzate :
    Include API per funzionalità come la geolocalizzazione, il drag-and-drop, e i WebSockets.

3. Principali Tag HTML

Ecco alcuni dei principali tag HTML:

  • < !DOCTYPE html > : Dichiarazione del tipo di documento; specifica che il documento è HTML5.

  • < html > : Elemento radice che contiene tutto il contenuto della pagina.

  • < head >: Contiene metadati e informazioni sulla pagina, come il titolo e i link ai file CSS.

  • < title > : Definisce il titolo della pagina, visibile nella scheda del browser.

  • < body > : Contiene il contenuto principale della pagina web.

  • < h1 > : Intestazione principale (livello più alto).

  • < p > : Definisce un paragrafo.

  • < a > : Definisce un collegamento ipertestuale.

  • < img >: Inserisce un'immagine; utilizza l'attributo src per specificare la sorgente dell'immagine.
