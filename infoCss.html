Info CSS

CSS (Cascading Style Sheets) è il linguaggio utilizzato per definire lo stile e la formattazione delle pagine HTML.

Principali stili CSS

  • color: Imposta il colore del testo
  • background-color: Imposta il colore di sfondo
  • font-size: Imposta la dimensione del testo
  • margin: Imposta i margini esterni degli elementi
