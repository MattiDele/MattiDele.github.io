Info CSS

Il CSS (Cascading Style Sheets, ossia "Fogli di stile a cascata") è un linguaggio di formattazione utilizzato per definire l'aspetto e il layout di un documento HTML o XML. Mentre l'HTML si occupa della struttura del contenuto (ad esempio, paragrafi, immagini, titoli), il CSS permette di stilizzare quel contenuto, cioè di determinare come esso appare visivamente nelle pagine web.

Principali stili CSS

  • CSS In Linea : Il CSS in linea è scritto direttamente all'interno di un tag HTML, usando l'attributo style. Le regole CSS vengono applicate solo all'elemento specifico e sono visibili insieme al codice HTML.

  • CSS Interno : Il CSS interno (o incorporato) viene inserito all'interno del documento HTML, nella sezione del documento, tra i tag style. Questo tipo di CSS è utile quando vuoi applicare stili a un'intera pagina, ma non vuoi o non puoi utilizzare un file esterno.

  • CSS Esterno : Il CSS esterno si scrive in un file separato con estensione .css, che poi viene collegato al documento HTML tramite il tag link nella sezione head. Questo è il metodo preferito per la maggior parte dei progetti, specialmente quelli di grande dimensione o che necessitano di uno stile uniforme su più pagine.

Tabella con le proprietà più importanti del CSS

Proprietà Descrizione
width Imposta la larghezza di un elemento.
height Imposta l'altezza di un elemento.
margin Aggiunge spazio esterno attorno a un elemento.
padding Aggiunge spazio interno tra il bordo dell'elemento e il suo contenuto.
color Imposta il colore del testo.
display Controlla come un elemento viene visualizzato.
